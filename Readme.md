# 🛡️ SANI – Smart Armored Nexus Integration

**Developers:** Aman Sinha, Saumya Suman, and Naveen Kumar Jha  
**Type:** AI-Powered Computer Vision & Assistance System  

## 📘 Overview
**SANI (Smart Armored Nexus Integration)** is an AI-driven computer vision and assistance system designed to enhance **situational awareness**, **threat detection**, and **field intelligence** in real-time.  
Built primarily for **Raspberry Pi–based environments**, SANI integrates **TensorFlow Lite**, **OpenCV**, and **Flask** to deliver intelligent visual recognition, voice assistance, and autonomous system control — all in a compact and low-power setup.

## ⚙️ Purpose
SANI aims to create a **lightweight, autonomous AI assistant** that functions effectively even on **limited hardware** and in **offline conditions**. It supports use cases across **military**, **defense**, and **disaster response** operations by analyzing live video feeds, detecting threats, and providing hands-free assistance.

## 🚀 Key Features
- 🎯 **Real-Time Object & Threat Detection:** Detects humans and lethal objects using optimized TensorFlow Lite models.  
- 💬 **Conversational AI Assistant:** Offers both text and voice-based interaction for command execution and information retrieval.  
- ⚡ **Offline Intelligence:** Operates entirely offline using local models (Llama.cpp / GPT4All).  
- 🧠 **Smart Memory System:** Retains key user and session data for improved response relevance.  
- 📈 **Performance Monitoring:** Displays live CPU, temperature, and uptime stats on request.  
- 🌐 **Remote Access & Control:** Allows SSH and VNC connectivity for mobile or remote operation.  
- 🗂️ **Local + Cloud Logging:** Stores important data locally and syncs to Google Sheets when marked significant.  

## 🔧 Technical Insight
SANI integrates **computer vision**, **speech recognition**, and **AI-driven automation** into a unified system. It uses **Flask** for interface control, **OpenCV** for camera processing, and **TensorFlow Lite** for lightweight inference. The system highlights potential threats with **yellow (probable)** and **red (confirmed)** outlines and supports user feedback-based escalation.
